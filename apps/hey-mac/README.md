# Hey Mac

"헤이 맥"이라고 부른 뒤 말로 Mac을 제어하는 메뉴 막대 앱입니다.
음성은 Whisper(WhisperKit)로 기기 안에서만 인식하며, 인터넷으로 전송되지 않습니다.

## 할 수 있는 것

| 분류 | 예시 |
|---|---|
| 음량 | "볼륨 올려줘", "볼륨 30으로", "소리 줄여줘", "음소거", "음소거 해제" |
| 밝기 | "화면 밝게", "화면 어둡게", "밝기 70으로" |
| 미디어 | "일시정지", "재생", "다음 곡", "이전 곡", "앞으로 감아줘", "뒤로" |
| 전원 | "잠자기", "화면 꺼줘", "화면 잠가줘" |
| 앱 | "사파리 열어줘", "크롬 종료해줘" |
| 기타 | "다크 모드 켜줘", "스크린샷 찍어줘" |

영어 명령도 됩니다("volume up", "pause", "open Safari", "go to sleep").

## 사용법

- 한 번에: **"헤이 맥, 볼륨 올려줘"**
- 나눠서: **"헤이 맥"** → 효과음과 "네, 말씀하세요" 표시 → 8초 안에 **"볼륨 올려줘"**
- 메뉴 막대 아이콘 > **지금 듣기**를 누르면 호출어 없이 바로 명령할 수 있습니다.

결과는 화면 위쪽 배너와 효과음으로 알려 줍니다.

## 빌드 및 실행

```sh
./scripts/build-app.sh
open build/HeyMac.app
```

macOS 15 이상, Apple Silicon 권장. 처음 실행하면 음성 인식 모델(수백 MB)을 내려받습니다.
Live Subtitles를 이미 쓰고 있다면 같은 모델을 함께 씁니다.

## 권한

- **마이크**: 호출어와 명령을 듣는 데 필요합니다.
- **손쉬운 사용**: 미디어 제어, 화면 잠금, 스크린샷, 앞/뒤 감기는 키 입력을 보내는 방식이라 필요합니다.
  음량·밝기·잠자기·앱 열기는 이 권한 없이도 됩니다.
- **자동화(System Events)**: 다크 모드 전환을 처음 쓸 때 묻습니다.

## 알아 둘 점

- 호출어는 인식기가 "헤이 맥", "해이 맥"처럼 조금씩 다르게 받아쓸 수 있어, 메뉴의 **호출어** 칸에 여러 표기를 쉼표로 넣어 둡니다. 잘 안 불리면 메뉴의 "들은 말"에 찍힌 표기를 추가하세요.
- 명령은 키워드로 해석합니다. 자유로운 문장이나 질문에는 답하지 못합니다.
- 재생/일시정지는 같은 미디어 키를 누르는 것이라, 지금 재생 중인지와 상관없이 상태를 뒤집습니다.
- 앞/뒤 감기는 맨 앞 창에 화살표 키를 보내는 것이라, 영상 플레이어가 맨 앞에 있어야 합니다.
- 밝기를 숫자로 지정하는 것은 내장 디스플레이에서만 됩니다(비공개 시스템 API 사용).
- 마이크를 계속 듣고 있으므로 메뉴 막대에 마이크 사용 표시가 켜져 있습니다.
