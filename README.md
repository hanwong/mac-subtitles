# Live Subtitles

Mac에서 재생되는 모든 소리(브라우저, 영상 플레이어, 화상 회의 등)를 실시간으로 받아써서 번역하고,
화면 하단에 고정된 자막으로 보여 주는 앱입니다.

- **시스템 오디오 캡처**: ScreenCaptureKit — 가상 오디오 드라이버 설치가 필요 없습니다.
- **음성 인식**: Whisper(WhisperKit) — 기기 안에서 처리되며 언어를 자동으로 감지합니다.
- **번역**: Apple Translation — 기기 안에서 처리되며 API 키나 비용이 없습니다.
- **자막 오버레이**: 항상 맨 위에 뜨고, 클릭이 통과하며, 전체 화면 앱과 모든 Space에서 보입니다.

## 요구 사항

- macOS 15 (Sequoia) 이상, Apple Silicon Mac 권장
- 빌드: Xcode 16 이상 (또는 Swift 6 툴체인)

## 빌드 및 실행

```sh
./scripts/build-app.sh
open build/LiveSubtitles.app
```

GitHub Actions의 Build 워크플로가 만든 `LiveSubtitles` 아티팩트를 내려받아 실행할 수도 있습니다.
(서명되지 않은 빌드라 처음에는 Finder에서 우클릭 > 열기로 실행해야 합니다.)

## 사용법

1. 앱 창에서 **자막 언어**(번역할 언어)를 고릅니다. **오디오 언어**는 기본이 자동 감지이고, 한 언어만 나온다면 직접 지정하는 편이 더 정확합니다.
2. **자막 시작**을 누릅니다. 처음에는 아래 권한을 요청합니다.
   - 처음 한 번 음성 인식 모델(수백 MB)을 내려받고 준비하는 데 몇 분이 걸립니다.
   - **화면 및 시스템 오디오 녹음** — 허용한 뒤 앱을 다시 실행해야 적용됩니다.
   - 번역 언어 팩이 없으면 다운로드 여부를 묻습니다.
     (시스템 설정 > 일반 > 언어 및 지역 > 번역 언어에서 미리 받아 둘 수도 있습니다.)
3. 소리가 재생되면 화면 하단에 자막이 나타납니다.

설정 창은 번역 세션을 유지하므로 닫지 말고 최소화해 두세요. 창을 닫으면 앱이 종료됩니다.

## 알아 둘 점

- 자막은 말이 잠깐 멈출 때마다(쉬지 않고 이어지면 최대 10초마다) 한 덩어리씩 인식·번역되어 나오므로 말보다 몇 초 늦게 뜹니다.
- 여러 언어가 섞여 나오면 언어마다 번역 언어 팩이 필요하고, 없으면 다운로드를 묻습니다.
- 배경 음악이나 소음만 있는 구간에서는 엉뚱한 문장이 인식될 수 있습니다.
- 빌드할 때마다 ad-hoc 서명이 바뀌어 macOS가 권한을 다시 물을 수 있습니다.
- 오디오 언어와 자막 언어가 같으면 번역 없이 받아쓰기 자막만 표시합니다.
